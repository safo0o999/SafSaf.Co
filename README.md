# متجر صفصف

حاسبة تكلفة الطباعة ثلاثية الأبعاد، إدارة الطلبات، ملخص الإنتاج، والتسويق للعملاء.

- الصفحة: `index.html` (تنشر على GitHub Pages)
- الاتصال بقاعدة البيانات: `config.js`
- طبقة البيانات (Supabase): `data.js`
- إعداد قاعدة البيانات: `supabase/schema.sql`

بيانات العملاء والطلبات ما تنحفظ في هذا المستودع؛ تنحفظ في Supabase ومحمية بتسجيل الدخول.
